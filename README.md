# Playbooks
A playbook library containing content for Cyber, Web Dev, and AI development students.


## What you can do with this

This repo is intended to be used by students at the Davis Catalyst for Cybersecurity, Web Dev, and AI Development. Inside are playbooks, guides, setup scripts, and other goodies for students to use. 

There is content that is domain specific but there are also general guides, so be aware that this repo is multi-purpose and is intended for a wide audience. 

## What this isn't

**The repo is NOT meant to be a place for storing code from individual projects; this is general use only!**
